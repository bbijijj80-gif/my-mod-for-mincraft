# Grandium Legends — Minecraft 1.12.2 Forge Mod

Мод добавляет **супер-редкие ресурсы** и легендарный меч **Клинок Анигилятора**, который убивает любого моба за **2 удара**.

## Требования

- **JDK 8** (Java 8) — обязательно для Minecraft 1.12.2
- **IntelliJ IDEA** (Community или Ultimate)

## Открытие в IntelliJ IDEA

1. Запустите IntelliJ IDEA
2. **File → Open** → выберите папку проекта (`build.gradle`)
3. Выберите **Open as Project**
4. Дождитесь загрузки Gradle (может занять 5–15 минут при первом запуске)
5. В терминале IDEA выполните:
   ```
   gradlew genIntellijRuns
   ```
6. Обновите Gradle-проект: **Gradle → Reload All Gradle Projects**

## Запуск для тестирования

- **Gradle → fg_runs → runClient** — запуск Minecraft с модом
- Или в терминале: `gradlew runClient`

## Сборка JAR

```
gradlew build
```

Готовый мод: `build/libs/grandium-1.0.0.jar` — скопируйте в папку `mods` Forge 1.12.2.

## Цепочка крафта

### 1. Первичная пыль (×2)
```
[D][E][G]
[L][R][Q]
[G][D][E]
```
- D = Алмаз, E = Изумруд, G = Золотой слиток
- L = Лазурит, R = Редстоун, Q = Кварц

### 2. Осколок пустоты
```
[P][B][P]
[E][N][E]
[P][G][P]
```
- P = Первичная пыль, B = Огненный стержень
- E = Эnder-жемчуг, N = Звезда Незера, G = Слеза гаста

### 3. Слиток грандиума
Плавка **Осколка пустоты** в печи.

### 4. Ядро грандиума
```
[I][N][I]
[D][V][S]
[I][T][I]
```
- I = Слиток грандиума, N = Звезда Незера
- D/S = Дыхание дракона, V = Осколок пустоты, T = Тотем бессмертия

### 5. Клинок Анигилятора
```
[ ][C][ ]
[I][I][I]
[ ][S][ ]
```
- C = Ядро грандиума, I = Слиток грандиума, S = Палка

## Предметы

| Предмет | Описание |
